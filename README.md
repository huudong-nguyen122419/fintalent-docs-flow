# Fintalent documentation

The operating manual for the Fintalent revenue engine — what each activity is, who owns it,
how far it is automated, and what has to change in the product to get it there.

## How this is organised

| Space | What lives here | Who reads it |
|---|---|---|
| **Ways of working** | Documentation standard, naming rules, templates | Everyone writing docs |
| **Revenue engine** | One page per activity in the matrix (`0.01` → `10.04`), grouped by stage | CEO, COO, CPO, CTO, Ops, Dev |
| **Platform** | Cross-cutting product docs that belong to no single activity — data model, integrations, runbooks | CTO, Dev |

## Start here

* **Aligning on scope or ownership?** → [Activity matrix](pages/activity-matrix.md)
* **Working on one activity?** → open its stage under [Revenue engine](pages/README.md)
* **Writing a new page?** → [Documentation standard](ways-of-working/documentation-standard.md)

## The one rule

The [Activity Matrix spreadsheet](pages/activity-matrix.md) is the source of truth for
**scope and ownership**. The **code** is the source of truth for **behaviour**. When a document
disagrees with either, the document is wrong.
