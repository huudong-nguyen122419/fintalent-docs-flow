# Revenue engine

The Fintalent revenue engine is 79 activities across 11 stages, from data foundation through to
expansion. Each activity has a primary owner today (short term), a target owner once the team
grows (mid term), and an automation target.

**Source of truth for scope and ownership:** [Activity matrix](activity-matrix.md) — a mirror of
`Fintalent Revenue Engine Activity Matrix - Draft v0.9.xlsx`. **Source of truth for behaviour:**
the code.

## Stages

| Stage | Activities | What it covers |
|---|---|---|
| [0. Data Foundation](data-foundation/README.md) | `0.01`–`0.11` | The classifications, records and governance everything else depends on |
| [1. Prospecting](prospecting/README.md) | `1.01`–`1.10` | Target lists, triggers, outreach, booking discovery |
| [2. Discovery & Scoping](discovery-and-scoping/README.md) | `2.01`–`2.04` | Understanding the problem and defining requirements |
| [3. Qualification Gate](qualification-gate/README.md) | `3.01`–`3.04` | Mandate, budget and delivery confidence — proceed or not |
| [4. Project Creation](project-creation/README.md) | `4.01`–`4.06` | Turning a qualified opportunity into a live project |
| [5. Sourcing](sourcing/README.md) | `5.01`–`5.06` | Building and working the invitation pool |
| [6. Shortlisting](shortlisting/README.md) | `6.01`–`6.06` | Screening, ranking, presenting candidates |
| [7. Candidate Selection](candidate-selection/README.md) | `7.01`–`7.07` | Interviews, feedback, finalist alignment |
| [8. Contracting](contracting/README.md) | `8.01`–`8.10` | Onboarding data, contracts, signature, activation |
| [9. Project Delivery](project-delivery/README.md) | `9.01`–`9.11` | Engagement health, invoicing, payouts, closure |
| [10. Expansion](expansion/README.md) | `10.01`–`10.04` | Satisfaction, follow-up, portfolio growth, advocacy |
