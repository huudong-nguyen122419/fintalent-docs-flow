## What each activity means

### `4.01` Create project record and draft client-facing brief

Turn the qualified opportunity into a clear project record and client-facing brief, including scope, title, description, timing, commitment and relevant commercial assumptions.

**Automation target:** AI-assisted project drafting and commercial-term checks  
**Note:** Commercial assumptions were clarified in Discovery and validated at the Qualification Gate.

### `4.02` Define project requirements and matching parameters

Translate the scope into clear responsibilities, must-haves, nice-to-haves and screening questions, and define the required seniority, geography, language and work setup.

**Automation target:** AI-assisted requirement drafting and structured field extraction

### `4.03` Define project pillars and taxonomy

Select standardized pillars and classifications that drive matching and evaluation.

**Automation target:** AI suggestions within governed taxonomy

### `4.04` Define sourcing and invitation strategy

Choose channels, filters, target pool, invitation logic and any extended sourcing required.

**Automation target:** AI-assisted sourcing plan

### `4.05` Perform four-eyes launch-readiness QA

Review scope, taxonomy, screening, pricing, sourcing logic and client assumptions before launch.

**Automation target:** Automated completeness and inconsistency checks  
**Note:** Senior Ops is the independent quality gate.

### `4.06` Launch project and complete internal handover

Set the project live and ensure Operations has the context required to execute sourcing.

**Automation target:** Workflow automation and launch checklist
