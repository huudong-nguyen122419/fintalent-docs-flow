# Templates

Every activity in the revenue engine gets the **same seven pages, one per stakeholder**. Copy the
`activity/` set, keep the file names, delete the sections you have not produced yet.

## The activity set

| Page | Stakeholder | Sections of the master prompt |
|---|---|---|
| [`README.md`](activity/README.md) | Everyone | §0 decision strip + verdict banner |
| [`for-the-ceo.md`](activity/for-the-ceo.md) | CEO | §1 executive summary + gate preview |
| [`for-operations.md`](activity/for-operations.md) | COO / Ops | §2 journey health map + symptom check · §4 known errors |
| [`for-product.md`](activity/for-product.md) | CPO / Product | §2 scenarios · §5 journeys & copy · §6 pain register |
| [`for-the-cto.md`](activity/for-the-cto.md) | CTO | §3 change briefs, backend + frontend |
| [`for-the-tech-team.md`](activity/for-the-tech-team.md) | Tech team | §7 surfaces & contracts · §8 gaps and open questions |
| [`for-developers.md`](activity/for-developers.md) | Junior / mid dev | §9 fix cards |

Generated by `prompts/stakeholder-master-doc.prompt.md` at the repo root.
Pass 1 fills `README.md`, `for-the-ceo.md`, `for-operations.md` and the quick-win cards in
`for-developers.md`. Pass 2 fills `for-the-cto.md` and the rest of `for-developers.md`.
`for-product.md` and `for-the-tech-team.md` are produced on demand.
