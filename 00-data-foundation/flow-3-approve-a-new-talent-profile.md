# Approve a new talent profile

> **0. Data Foundation** &nbsp;·&nbsp; 1 activity &nbsp;·&nbsp; steps not written yet

Work the queue of newly submitted talent profiles: read one, approve or reject it, fix classification errors, attach it to the right company.

## Why these are one flow

One activity, one flow. It is queue-driven rather than continuous, and it is the only activity in this stage where an item arrives and waits for a decision.
