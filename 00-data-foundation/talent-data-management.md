# Talent Data Management

> **0. Data Foundation** &nbsp;·&nbsp; 2 activities &nbsp;·&nbsp; flows not written yet

The standard a talent profile is held to, and the review that applies it to each profile that arrives.

## Why these belong together

Same object: the talent profile. `0.07` sets the standard, `0.08` applies it one profile at a time. The reviewer in `0.08` is enforcing exactly what `0.07` defines, so the two are read together or not at all.

**What still differs.** `0.08` is queue-driven — an item arrives and waits for a decision — while `0.07` is continuous maintenance.
