# Platform

Cross-cutting product documentation that belongs to no single activity in the matrix — the shared
foundations several activities sit on.

**Rule of thumb:** if a page answers *"how does this part of the system work?"* it belongs here.
If it answers *"how do we run this activity and what has to change?"* it belongs under
[Revenue engine](../pages/README.md).
